# hfd-data-ops

Operational scripts and utilities for the foss4lh archive.

## Tools
- **Georectifier**: Automation for aligning raw scans to the British National Grid.
- **Compressor**: Scripts to chunk large datasets for GitHub upload (up to 2GB per chunk).
- **Converter**: Tools to transform .arw/.tiff into web-native formats (WebP, COG).
